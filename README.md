# Sayyid Ahmed Mushthaq & Fathima Sana · Wedding Reception

A digital wedding invitation. Guests tap "Open Invitation" to draw back burgundy velvet curtains and reveal the arched invitation card, with a separate card for the Nikah.

Built with React, TypeScript, Vite, Tailwind CSS and Framer Motion. Set `SONG_VIDEO_ID` in `src/App.tsx` to enable background music.
